# Filing the slices

The `refine` skill sends you here when "Which step" says to file the slices.

1. **Change the slices** as the owner answered.
2. **File each slice, in order.** Pick its type and write its title and body as steps 1, 2, 4, 5 and 6 of the `ticket` skill say, in `.refine/<slice>.md`. File each criterion as you believe it should read: you cannot change a filed ticket ([A634](../../../factory/decisions/634.md)). An Initiative's "Scope" holds what is in, what is out and each decision of yours the engineer cannot read from the criteria; it restates no criterion ([T709](../../../factory/decisions/709.md)). Its "States" rows are the map's, and the journey file's, for its screens, each screen and state worded as there; a row another slice builds says "unchanged". It lists `product/journeys/<name>.md` under "Docs to update": the first slice writes the journey there, and later ones update it. `file-slice.sh` refuses any other ([T606a](../../../factory/decisions/606.md)). The body holds a line `After #<n>` on its own for each earlier slice whose code, table, screen, behaviour or finding it needs; slices that only change the same file get none ([T353c](../../../factory/decisions/353.md)). A slice whose screen Dara designed says in its body that it builds that design, with the address of its HTML file from her latest comment ([A571c](../../../factory/decisions/571.md)). `factory/scripts/file-slice.sh <idea> <type> "<title>" .refine/<slice>.md` files the ticket, says so on the idea and prints the ticket's number, or prints what its template refuses. Never file a slice the idea already says was filed ([A353g](../../../factory/decisions/353.md)).
3. **Say what you filed,** with `propose.sh`: one comment listing the tickets in order, what the owner answered and what that changed, and each criterion you corrected and why. It leaves the owner no criterion to read or correct. Only where you cannot tell what one should say, file your best reading and ask the owner to answer in a comment on that ticket, which its engineer reads.
