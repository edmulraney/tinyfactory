### #443. A label that is not `revert` starts no job in `revert.yml`

- **Set:** `revert.yml` starts when a label is added to a ticket, and a condition on its one job runs it for the `revert` label alone (ticket #443; `decisions.md` [M443b](../decisions/443.md)). It replaces a start by command, which ran only when asked.
- **Protects:** Actions minutes.
- **Why:** GitHub starts the workflow for every label added to every ticket, and a job that ran to ask a script which label it was would be billed a minute each time.
- **Numbers, before:** 1 billed minute for each ticket the owner took back, and none otherwise.
- **Numbers, after:** worked out, not measured. The same 1 billed minute for each `revert` label added. A run for any other label holds one skipped job, which is billed nothing, as the skipped jobs of `implement.yml` and `refine.yml` are for the same event.
- **The event-driven way:** the label is the event, and nothing is scheduled.
- **Automated:** yes.
