### #574. A label that names no defect starts no job in `retro.yml`

- **Set:** `retro.yml` also starts when a label is added to a ticket, and a condition on its one job runs it for the `bug` label alone. A ticket whose defect a retro has looked at ends at the step that gathers its facts, before any agent starts (ticket #574; `decisions.md` [A574a](../decisions/574.md), [A574b](../decisions/574.md)).
- **Protects:** Actions minutes, and the Claude usage the agents share.
- **Why:** GitHub starts the workflow for every label added to every ticket, and a job that ran to ask a script which label it was would be billed a minute each time. A second label on one ticket would otherwise pay an agent to repeat a lesson.
- **Numbers, before:** no retro for a defect met in use. Measured on 21 November 2026 over the 40 retros before it: a retro's run took 2.1 minutes at the median and 3.9 at most, and its session cost $0.72 at the median and $1.96 at most.
- **Numbers, after:** worked out, not measured. One such run for each ticket labelled `bug`, and 1 billed minute for a second label on that ticket. A run for any other label holds one skipped job, which is billed nothing, as the skipped job of `revert.yml` is ([entry #443](443.md)).
- **The event-driven way:** the label is the event, and nothing is scheduled.
- **Automated:** yes.
