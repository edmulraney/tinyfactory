### #691. The idle look starts a conflict's fix round once for a commit

- **Set:** `flag-idle.sh` starts `fix.yml` for an idle pull request in conflict only when no comment on its ticket records such a start for its last commit (ticket #691; `decisions.md` [A691b](../decisions/691.md)).
- **Protects:** Actions minutes and Claude usage.
- **Why:** the look runs every six hours ([entry #271](271.md)), and a round that never begins, or leaves the conflict, would otherwise be started at each look.
- **Numbers, as set:** worked out, not measured: a workflow cannot run before it merges. One `fix.yml` run for each commit left idle in conflict, the run a person was told to start until this ticket, and one call more in the look to read the ticket's comments.
- **Numbers, the alternatives:** a start at every look, four `fix.yml` runs a day for each pull request whose conflict a round does not settle, each billed at least one minute and an engineer's session when it begins.
- **Automated:** yes.
