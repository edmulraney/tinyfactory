| S421a | Each setup script prints through `present.sh`: a numbered heading, a mark for how a step ended, and one block of what the owner must do. | On 18 November 2026 the owner could not tell, in a wall of text, what to do at the board and board-token steps. | Escape codes in each script: thirteen copies to keep the same. | S421b | `present.sh` styles only where the script's output is a terminal and `NO_COLOR` is unset, and decides that once, when it is sourced. | A block made inside `$( )` for Python to print is then styled as the terminal the owner reads, and a pipe gets no escape code. | Asking at each call: inside `$( )` the output is never a terminal. A variable that forces colour: an option nobody needs. | #421 |
| S421c | A step that leaves something to the owner writes it to the file `SETUP_NEEDS_OWNER` names, and `bootstrap.sh` lists those at the end of a run. | A step that needs the owner still exits 0, so only what it wrote tells `bootstrap.sh` that the setup is not finished. | An exit code of its own: `apply-setup.sh` and a step run alone read it as a failure. Reading the steps' output through `tee`: the output is then no terminal. | #421 |
| S421d | The block's box has a top, a left side and a bottom, and no right side. | A right side needs each line's width on screen, which bash 3.2 cannot tell for `→` or in a locale that counts bytes. | A full box padded by `${#line}`: its right side breaks on a line with `→`. `tput` and `wc -m`: more outside calls for decoration. | #421 |
